# Task-1
ACRYLIC is a responsive front-end website designed for a Kids Art Center that showcases creative art classes such as Drawing, Painting, Sculpting, and Illustration. This project was developed using HTML5 and CSS3 with the goal of creating a visually appealing, kid-friendly, and structured homepage layout.
The website includes a fixed navigation header with branding and authentication buttons, a hero section with a headline, description, featured image, and call-to-action button, an informational highlight section, and a classes section displaying four creative courses using a CSS Grid layout.
Each class is presented in a card format with images, titles, and hover effects to enhance user interaction. The footer section contains social media icons integrated using Font Awesome, address details, and a styled contact form with input fields for name, email, and message.
The index.html file focuses on structuring the webpage using semantic HTML elements such as header, section, and footer to ensure proper organization and readability. It demonstrates clean layout planning, structured content flow, and form implementation.
The style.css file is responsible for the visual styling and responsiveness of the website. It includes global reset styling, a pastel color theme suitable for a children’s art center, rounded containers, shadow effects, hover animations, and proper spacing for improved UI design. Flexbox and CSS Grid were used to create balanced layouts, while media queries were implemented to ensure the website adapts smoothly to desktop, tablet, and mobile screens.
